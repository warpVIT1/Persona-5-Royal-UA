# Сторінка мода на GameBanana

Розділ: **Persona 5 Royal (PC)** → Mods → категорія **Translations** (або Other/Misc, якщо такої немає).

## Name

Persona 5 Royal — Українська локалізація (Ukrainian Translation)

## Summary (коротко, до 100 символів)

Фанатський переклад Persona 5 Royal українською мовою / Ukrainian fan translation

## Description

**Українська**

Фанатський переклад Persona 5 Royal (Steam) українською мовою.

Що перекладено:
- усі діалоги сюжету, Конфіденти, телефонні чати;
- меню, предмети, навички, персони, вороги, підказки, мапи;
- репліки навігаторів у бою (Морґана, Футаба, Акечі);
- екран збереження, «Нова гра+», системні повідомлення;
- шрифт з українськими літерами (ґ, є, і, ї);
- введення імені героя українською (у розкладці ЙЦУКЕН);
- перетворення імен зі збережень інших перекладів (вмикається в налаштуваннях мода).

Ще в роботі: кросворди, текстури з написами.

Встановлення:
1. Встановіть [Reloaded-II](https://github.com/Reloaded-Project/Reloaded-II/releases) і додайте до нього Persona 5 Royal.
2. Натисніть кнопку 1-click install на цій сторінці (або розпакуйте архів у `Reloaded-II/Mods`).
3. Увімкніть мод «Persona 5 Royal — Українська локалізація» (Persona 5 Royal Essentials встановиться автоматично).
4. Мова гри в Steam — **English**.

Оновлення приходять автоматично через Reloaded-II.
Сирці перекладу: https://github.com/warpVIT1/Persona-5-Royal-UA

**English**

Ukrainian fan translation of Persona 5 Royal (Steam). Story, menus, items, battle navigator lines, save screen,
Cyrillic font and Ukrainian name entry. Requires Reloaded-II and Persona 5 Royal Essentials; set the game language
to English. Source: https://github.com/warpVIT1/Persona-5-Royal-UA

## Файли

Завантажити архів з `C:\P5R_UA_publish` (Reloaded-II → Publish Mod, Publish Target = **GameBanana**,
назва латиницею, напр. `Persona5Royal_UA`).
