# Сторінка мода на GameBanana

Розділ: **Persona 5 Royal (PC)** → Mods → категорія **Translations** (або Other/Misc, якщо такої немає).

## Name

Persona 5 Royal — Українська локалізація (Ukrainian Translation)

## Summary (коротко, до 100 символів)

Фанатський переклад Persona 5 Royal українською мовою / Ukrainian fan translation

## Description

**Українська**

Фанатський переклад Persona 5 Royal (Steam) українською мовою.

Що перекладено:
- усі діалоги сюжету, Конфіденти, телефонні чати, імена мовців;
- меню, предмети, навички, Персони, вороги, підказки;
- мапа, станції та описи районів, місця у списку збережень;
- журнал активності, нотатки календаря, ранги соціальних характеристик;
- меню навчальних довідок і сюжетних розділів, довідка Оксамитової кімнати;
- коментарі Фан-сайту;
- репліки навігаторів у бою (Морґана, Футаба, Акечі), екран збереження, «Нова гра+»;
- субтитри аніме-роликів (переклад команди [LBK](https://lbklauncher.com/));
- шрифт з українськими літерами (ґ, є, і, ї), перемальовані текстури;
- введення імені героя та назви команди українською (розкладка ЙЦУКЕН).

Ще в роботі: рядки інтерфейсу всередині P5R.exe (дні тижня, тактика, частина бойових написів), кросворди,
частина текстур із написами.

Встановлення:
1. Встановіть [Reloaded-II](https://github.com/Reloaded-Project/Reloaded-II/releases) і додайте до нього Persona 5 Royal.
2. Натисніть кнопку 1-click install на цій сторінці (або розпакуйте архів у `Reloaded-II/Mods`).
3. Увімкніть мод «Persona 5 Royal — Українська локалізація» (Persona 5 Royal Essentials встановиться автоматично).
4. Мова гри в Steam — **English**.
5. Запускайте гру через Reloaded-II. Оновлення приходять автоматично.

Запуск зі Steam кнопкою «Грати»:
1. Один раз запустіть гру через Reloaded-II (мод сам скопіює лаунчер).
2. Steam → Persona 5 Royal → Властивості → Загальні → Параметри запуску → вставте:
   `cmd /c ""%LOCALAPPDATA%\P5R_UA\launcher\P5R_UA_Launcher.exe" %command%"`
3. Далі просто натискайте «Грати». Не вмикайте «Deploy ASI Loader» у Reloaded-II — з ним гра зависає.

Нюанси:
- Під час набору імені видно латиницю — кирилицею ім'я стає після підтвердження.
- Імена зі збережень інших перекладів: Configure Mod → «Перетворити ім'я зі старого перекладу».
- Якщо раніше ставили інший переклад прямо в теку гри — спершу Steam → Перевірити цілісність файлів.
- Проблеми — надсилайте `Reloaded-II\Mods\p5rpc.ukrainian\exebmd_log.txt` і скріншот.

Сирці перекладу: https://github.com/warpVIT1/Persona-5-Royal-UA

**English**

Ukrainian fan translation of Persona 5 Royal (Steam): story, menus, items, map and stations, calendar and activity
log, tutorials, Phan-Site, battle navigator lines, anime cutscene subtitles, Cyrillic font and Ukrainian name entry.
Requires Reloaded-II and Persona 5 Royal Essentials; set the game language to English. Optional Steam "Play" launch:
run once via Reloaded-II, then set the launch options to
`cmd /c ""%LOCALAPPDATA%\P5R_UA\launcher\P5R_UA_Launcher.exe" %command%"`.
Source: https://github.com/warpVIT1/Persona-5-Royal-UA

## Файли

Завантажити архів з `C:\P5R_UA_publish` (Reloaded-II → Publish Mod, Publish Target = **GameBanana**,
назва латиницею, напр. `Persona5Royal_UA`).
