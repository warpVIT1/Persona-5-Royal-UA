# Посібник перекладача P5R

Робочі правила етапу 4. Термінологія — тільки за `glossary.csv` (усе затверджено).

## Робочий цикл

```sh
python tools/scripts/tr.py next --path EN/EVENT_DATA/MESSAGE/E100 --n 80   # порція рядків -> work/batch.json
#   переклад -> work/answers.json  {"<k>": "<текст>"}
python tools/scripts/tr.py apply work/answers.json                         # запис + пам'ять перекладів + перевірка
python tools/scripts/tr.py stats --path EN/EVENT_DATA/MESSAGE              # прогрес
```

Пам'ять перекладів: однакова репліка того самого мовця перекладається один раз і потрапляє в усі файли.

## Технічні правила

- Коди `[clr N]`, `[fName]`, `[lName]`, `[var N]`, `[ref …]`, `[stLabel …]` зберігати; порядок можна
  змінити, якщо цього вимагає синтаксис (пара `[clr N]…[clr 27]` має обгортати те саме слово).
- `[n]` — перенос рядка; розставляємо заново під український текст.
- Вікно діалогу: **3 рядки × 44 символи**; варіанти вибору: **1 рядок × 32**; описи предметів: **49 × 10**
  (`tools/scripts/limits.py`). Ліміти символьні, уточнимо в пікселях на етапі 5.
- Українська довша за англійську на 10–20%, тож перекладаємо стисло, без втрати змісту й інтонації.
- Лапки «», тире —, три крапки …; апостроф — `'` (U+0027; єдиний апостроф, який точно буде у шрифті).
- `[fName]` — ім'я героя (вводить гравець, чоловічий рід); не відмінюється, тож будуємо фразу так,
  щоб ім'я стояло в називному або кличному відмінку без закінчення.

- `[stLabel N]` підставляє назву соціального показника в **називному відмінку** (0 Знання, 1 Чарівність,
  2 Вправність, 3 Сміливість, 4 Доброта). Будуй фразу нейтрально: «показник [stLabel 3] замалий»,
  «показник [stLabel 4] зріс» — не «бракує [stLabel 3]».

## Звертання «ти» / «ви»

- Однолітки, члени команди між собою — **ти**.
- Учні до вчителів, лікарів, дорослих, незнайомців — **ви**; дорослі до підлітків — **ти**.
- Протагоніст до Соджіро — **ви** (на початку чужі люди; так і лишається з повагою), Соджіро до нього — **ти**.
- Ігор і Лавенца до гостя — **ви**; Кароліна й Жюстіна (наглядачки) до «в'язня» — **ти** (зверхньо).
- Сае на допиті до протагоніста — **ти** (холодна зверхність прокурора).
- Хару говорить ввічливо, але з друзями на **ти**; ввічливість передаємо лексикою.
- Тіні-володарі Палаців — **ти** (зневага).

## Голоси персонажів

- **Рюджі** — грубувато-розмовний, емоційний: «Чорт!», «Та ну!», «Агов», «чувак» (dude), скорочення,
  вигуки. Без суржику й матів, але сміливо розмовно.
- **Морґана** — гонористий, повчальний, «джентльмен»: «Я тобі не кіт!», до Анн — «леді Анн».
  Звертання до героя — «ти»; часто командує «Ходімо спати».
- **Анн** — щира, жвава, емоційна; сучасна молодіжна мова без сленгу-перебору.
- **Юсуке** — піднесений, театральний, книжні слова й естетика, трохи кумедна серйозність.
- **Макото** — формальна, точна, логічна; повні речення, мінімум сленгу.
- **Хару** — м'яка, ввічлива, трохи наївна; «будь ласка», «дякую вам» у формальних сценах.
- **Футаба** — інтернет-сленг, гік-жаргон, різкі перепади: «ЛОЛ», «нуб», «квест»; із чужими — затинається.
- **Акечі** — ввічливий, гладкий, медійний «принц»; у розв'язці — холодний і зневажливий.
- **Касумі/Суміре** — ввічлива, наполеглива, спортивна дисципліна.
- **Соджіро** — буркотливий, сухий гумор, коротко: «Малий», «Не роби дурниць».
- **Ігор** — урочистий, загадковий; **Лавенца** — ввічлива, трохи наївна; **Кароліна** — різка й
  крикливa; **Жюстіна** — холодна, канцелярська.
- **Тіні-володарі** — гіперболізовані пороки: Камошіда — самовдоволений «король», Мадараме —
  пихатий «митець», Канешіро — вульгарний хвалько.

## Що не перекладаємо

Сторінки `lang: ja` (японські заглушки, `docs/japanese_leftovers.md`) і службові (`dummy`, `BLANK`).

## Японські суфікси та звертання (рішення власника, 2026-10-17)

В українській немає -сан/-кун/-чан/-сама/-доно/-сенсей/семпай — їх **адаптуємо**, не транслітеруємо:
- `Sae-san`, `Akechi-kun`, `[lName]-kun`, `Futaba-chan` → просто ім'я: «Сае», «Акечі», «[lName]», «Футабо!».
  Повагу передаємо іншими засобами, якщо треба: «пані Сае», «пане Шідо», ввічливе «ви».
- Пестливе `-chan` → пестлива форма чи просто ім'я: «Мона-чан» → «Мона»/«Монечко».
- `Senpai` (Касумі до протагоніста тощо) → за змістом: звертання — «[lName]» неможливе (коди не додаємо),
  тож «старшенький», «друже», ім'я з контексту, або перебудувати фразу; у розповіді — «старший товариш»,
  «старшокласник». Слова «семпай» у перекладі бути не повинно.
- `Sensei` → «пане вчителю / пані вчителько», «лікарко» (Такемі), «вчитель» у розповіді.
- Морґана — з «ґ».
