# Глосарій: принципові рішення

Ці рішення визначають тисячі рядків, тому їх варто затвердити до перекладу. Для кожного — мій варіант
(уже застосований у `glossary.csv` зі статусом `proposed`) та альтернативи. Затверджене позначай у
`glossary.csv` статусом `approved`: `build_glossary.py` такі рядки більше не перезаписує.

## 1. Транслітерація японських імен і назв

**Пропоную:** система Коваленка — норма української Вікіпедії та словників.

| яп. | укр. | приклад |
|---|---|---|
| し / ち / つ | сі / ті / цу | Камосіда, Тіхая, Цукійомі |
| じ / ず | дзі / дзу | Рюдзі, Судзуй |
| しゃ しゅ しょ | ся сю сьо | Сюдзін |
| ちゃ ちゅ ちょ | тя тю тьо | Аояма-Іттьоме |
| g | г | Кітагава, Того |
| ん перед б/п/м | м | Дзімботьо |
| ii | ії | Ніїдзіма |
| довгі голосні | не позначаємо | Оя, Корю |

**Альтернатива:** «англізована» практика фанатів — Рюджі, Шібуя, Акечі, Кітаґава. Звичніша гравцям,
але суперечить нормі. Для найпомітніших імен альтернативи вказані в колонці `alternatives`.

## 2. Японські іменні суфікси (-kun, -san, -senpai, -sensei)

EN-версія їх здебільшого прибирає, лишаючи «senpai» та «sensei» в окремих місцях.
**Пропоную:** іти за EN — не додавати; «senpai» → «семпай» лише там, де він є в англійському тексті.

## 3. Персони

**Пропоную:** усталені українські форми міфологічних і літературних імен (Вельзевул, Гавриїл, Цербер,
Ісіда, Кухулін, Арсен, Йоганна), японські — за Коваленком (Ідзанагі, Сейтен Тайсей).
**Альтернатива:** лишати латиницею — простіше, але виглядає як недоперекладене.

## 4. Навички

**Пропоную:** серії заклинань (Agi, Bufu, Zio, Garu, Psi, Frei, Kouha, Eiha, Megido, Dia, -kaja/-nda) —
вигадані слова, транслітеруємо: Агі / Агілао / Агідайн, Дзіо, Тарукадзя. Описові назви (Lunge,
Heat Riser, Rebellion) перекладаємо. Після затвердження правила доповню решту ~930 навичок.

## 5. Кодові імена

**Пропоную:** перекладати — Джокер, Череп, Пантера, Лис, Королева, Оракул, Ворон, Віолетта;
«Нуар» лишається французьким, «Мона» — без змін. У яп. оригіналі це англійські слова, тобто
гравець мав розуміти їхнє значення.

## 7. Інтерфейсні скорочення

**Пропоную:** HP/SP латиницею (як у більшості українських локалізацій); St/Ma/En/Ag/Lu → Сил/Маг/Вит/Спр/Удч;
стихії — короткі форми (Фіз, Вогн, Ел, Ядер) через обмежену ширину іконок.

## Обмеження довжини

Назви Персон, навичок, предметів показуються в меню фіксованої ширини. Точні ліміти визначимо на
етапі 5, коли буде відомо ширину кириличних гліфів у шрифті; довгі варіанти тоді скоротимо.
