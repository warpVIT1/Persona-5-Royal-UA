# Завдання агента-перекладача (P5R → українська)

Проєкт: `D:\ozwuchka\RaccoonHouse\персона 5` (bash: `/d/ozwuchka/RaccoonHouse/персона 5`).
Ти перекладаєш свою ділянку гри з англійської українською. Інші агенти паралельно працюють з іншими
ділянками — інструменти це враховують.

## Перед початком прочитай

1. `docs/translation_guide.md` — рід мовців, «ти/ви», голоси персонажів, технічні правила. **Обов'язково.**
2. Терміни підказуються прямо в порції (`gl: Kamoshida=Камошіда`). Глосарій затверджено — відхилятися не можна.
   Якщо треба знайти термін, якого немає в підказці: `grep -i "^Назва," glossary.csv`.

## Цикл роботи (повторюй, доки ділянка не скінчиться)

```bash
cd "/d/ozwuchka/RaccoonHouse/персона 5"
PYTHONIOENCODING=utf-8 python tools/scripts/tr.py next --agent <ІМ'Я> --path <ПРЕФІКС> --n 80
```
Команда друкує порцію: `#k [мовець] (символів×рядків) англійський текст`, контекст (`ctx`) і терміни (`gl`).
Переклади все й запиши файл `work/agents/<ІМ'Я>/answers.json` інструментом Write:
```json
{"0": "переклад...", "1": "переклад..."}
```
Потім:
```bash
PYTHONIOENCODING=utf-8 python tools/scripts/tr.py apply --agent <ІМ'Я> work/agents/<ІМ'Я>/answers.json
```
- `ERROR` — рядок НЕ записано. Виправ і подай лише виправлені `k` новим answers.json, знову `apply`.
  (Невдалі рядки лишаються в порції, `next` не видасть нову, доки ти їх не закриєш.)
- `WARN` про довжину або термін — виправ, якщо це можна зробити без втрати змісту; інакше лиши.
- Коли `next` пише `NOTHING LEFT under this path` — переходь до наступного префікса зі свого списку.

Виправити вже застосований рядок (після успішного `apply` він зникає з порції):
```bash
PYTHONIOENCODING=utf-8 python tools/scripts/tr.py fix --path <ПРЕФІКС_ФАЙЛУ> --en "<фрагмент англійського тексту>" --uk "<новий переклад>"
```

## Правила перекладу

- Природна сучасна українська, без кальок і суржику. Зміст, інтонація, жарти — як в оригіналі.
- Коди `[clr N]`, `[fName]`, `[lName]`, `[var N]`, `[ref …]`, `[stLabel …]`, `[x …]` — переносити всі, без змін.
  `[n]` — перенос рядка: розставляй заново під українську фразу, щоб рядки не перевищували ліміт
  `(символів×рядків)` з порції. Не додавай рядків понад ліміт.
- Літеральні квадратні дужки в тексті — `\[` і `\]`.
- Лапки «», тире —, три крапки ..., апостроф — звичайний `'`.
- Рід мовця визначає закінчення дієслів («я зробив/зробила»). Протагоніст — чоловічого роду.
  Варіанти вибору (`[sel]`) — репліки протагоніста.
- `[fName]`/`[lName]` — ім'я героя; не відмінюється, будуй фразу так, щоб воно стояло без закінчення.
- Не перекладай імена в квадратних кодах і не змінюй числа в кодах.
- Однакові рядки підставляються автоматично в усі файли — перекладай нейтрально, якщо контекст неясний.

## Заборонено

- Редагувати будь-які файли, крім `work/agents/<ІМ'Я>/answers.json`.
- Запускати git, видаляти файли, змінювати скрипти, глосарій чи інші ділянки.
- Читати великі JSON-файли напряму (`strings_uk/`, `strings_en/`) — тільки через `tr.py`.
